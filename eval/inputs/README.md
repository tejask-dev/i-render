# Demo inputs

The robot drawings are original constructed test sketches. They exercise different silhouettes and functions. Use them with the photo upload to exercise vision. Selecting an example inside the UI uses a separately labelled predefined RobotSpec.

Two real reference photographs support repeatable drawer recognition. Both are resized for the local demo. Bring the team's own parts and photograph them under venue lighting for the final rehearsal.

- Evan-Amos, LED flashlight, public domain. [Original photograph](https://commons.wikimedia.org/wiki/File:Led-flashlight.jpg)
- Editor abcdef, radio-controlled car on ground, CC0. [Original photograph](https://commons.wikimedia.org/wiki/File:Radio_controlled_car_on_ground.JPG)

The combined drawer reference places these two photographs side by side to test recognition of multiple objects.
