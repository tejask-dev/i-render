# Design tokens

Implemented as CSS custom properties at the top of [frontend/style.css](../../frontend/style.css). Original values are in [../original/README.md](../original/README.md#visual-language-from-stylecss).

## Color
| Token | Value | Role |
| --- | --- | --- |
| `--bg` | _tbd_ | Page background |
| `--surface` | _tbd_ | Cards, panels |
| `--text` | _tbd_ | Primary text |
| `--text-muted` | _tbd_ | Secondary text |
| `--border` | _tbd_ | Dividers |
| `--primary` | _tbd_ | Main action |
| `--accent` | _tbd_ | Highlights, Rendi |
| `--success` / `--warning` / `--danger` | _tbd_ | Status |

Contrast: text ≥ 4.5:1, large text and UI ≥ 3:1.
